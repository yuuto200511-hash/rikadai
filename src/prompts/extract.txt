## データベースで検索できる項目と選択肢
- building（建物）: $buildings
- room（教室番号。「K503」など）: 質問文の表記のまま
- floor（階）: 整数
- outlets_required（電源が必要か）: true / null
- min_seats（必要な座席数）: 整数
- chair_type（椅子の種類）: $chair_types
- standing（立ち作業）: $standing
- quietness_max（静粛性の上限。静かさが必要なとき、許せるにぎやかさの段階）: $quietness のどれか
- quietness_min（静粛性の下限。話す・通話するとき、少なくとも必要な段階）: $quietness のどれか
- food（飲食、制限が厳しい順）: $food
- task_light（作業灯）: $task_light
- date（日付）: YYYY-MM-DD。「今日」「明日」「明後日」「10/2」など、日付が決まる表現のとき
- weekday（曜日）: $weekdays。「金曜」のように曜日だけのとき（date が決まるときは null）
- period（時限）: 整数（時刻は $period_times。6限以降もそのまま整数で入れる）
- now（「今」「今から」「今すぐ」など現在の時刻での利用か）: true / null

## 質問の種類（intent）
- "notice"（お知らせの確認）: 施設のお知らせ・使えない場所・工事・閉鎖・臨時の変更を尋ねる質問。例:
  「使えない部屋はある？」「工事しているところは？」「最近のお知らせは？」「図書館のお知らせは？」
  このとき、建物や場所の名前（「図書館」「21号館」「閲覧室」など）が質問文に書かれていれば notice_place に入れる
  （建物なら上の建物一覧の表記に揃え、building にも入れる。「閲覧室」のような建物以外の場所は notice_place だけに入れる）。
  「教室」「部屋」「場所」「席」「スペース」のような一般的な言い方は名前ではないので、notice_place も building も null にする
  （例:「お知らせで使えない教室ある？」→ notice_place: null, building: null）。ほかの項目は null でよい。
- "chat"（挨拶・お礼・雑談）: 「こんにちは」「ありがとう」「よろしく」「何ができるの？」など、検索やお知らせの確認を求めていない発言。
  supported は true、ほかの項目は null にする。
- "review"（口コミの確認）: 口コミ・利用者の声・評判・感想・レビューの内容を知りたい質問。例:
  「閲覧室の口コミを教えて」「おすすめ1の口コミは？」「そこの評判はどう？」「最近の口コミを見せて」
  - 会話で紹介したスポット（「おすすめ1」「そこ」「さっきの場所」など）を指していれば、review_spot_ids に
    これまでの会話の「紹介したスポット」の ID を入れる（例: ["S046"]。「全部」なら紹介したスポットすべて）。
  - 場所の名前が書かれていれば、質問文の表記のまま review_place に入れる（例:「閲覧室のソファ」「壁沿いデスク」）。
    建物の名前なら building にも入れる。
  - 対象が書かれていなければ、review_spot_ids・review_place は null（最近の口コミを答える）。ほかの項目は null でよい。
  - 「静かな場所を口コミつきで教えて」のように、条件で場所を探しつつ口コミも知りたいときは intent: "spot" にし、
    want_reviews: true にする。
- "spot"（作業スポット探し）: それ以外。notice_place は null。

## 会話の続き（follow_up）
- 今回の質問が、直前のスポット探しへの条件の追加・変更・取り消しなら follow_up: true にし、
  直前の条件（「これまでの会話」の最後のスポット探しの「検索条件」）を引き継いだうえで、今回の発言を反映した「全体の条件」を出力する。
  続きの例:「じゃあ〜」「あと〜」「さらに〜」「その中で〜」「〜もできるところ」「〜だったら？」「やっぱり〜」、
  条件だけの短い発言（「飲み物OKで」「3人で」「明日の4限は？」）。
  - 追加: 直前「静かで電源がある場所」→ 今回「飲み物も飲みたい」→ quietness_max: "小声可", outlets_required: true,
    food: ["飲み物のみ", "食事可"]
  - 変更: 直前「図書館で静かな場所」→ 今回「21号館だったら？」→ building: "21号館", quietness_max: "小声可"
    （変えた項目と両立しない項目、例えば前の建物の floor・room は null にする）
  - 取り消し: 今回「電源はなくてもいい」→ outlets_required: null（ほかは引き継ぐ）
  - 日付・時限（date・weekday・period・now）も、変更されなければ引き継ぐ。
- 新しく一から探す質問（条件をすべて言い直している・別の目的になった）、お知らせ・挨拶・口コミの確認、
  または「これまでの会話」が「（なし）」なら follow_up: false にし、直前の条件を引き継がない。

## ルール
- 質問文で言及されていない項目は null にする（会話の続きで引き継ぐ条件は除く）。推測で条件を足さない。
- 選択肢のある項目は、必ず上の選択肢の文字列だけを使う（選択肢にない値を作らない）。
- 曖昧な表現は、当てはまる区分をすべて候補リストに入れる。例:
  - 「静か」「集中したい」「勉強に集中」→ quietness_max: "小声可"（私語厳禁と小声可に一致）
  - 「完全に無音」「私語禁止」→ quietness_max: "私語厳禁"
  - 「話しながら」「グループで」「相談しながら」→ quietness_min: "会話可"（会話可と通話可に一致）
  - 「通話」「電話」「オンライン会議」「オンライン面接」「Zoom」→ quietness_min: "通話可"（通話可だけに一致）
  - 「飲み物を飲みながら」→ food: ["飲み物のみ", "食事可"]
  - 「ご飯を食べながら」「昼食」「お弁当」→ food: ["食事可"]
  - 「ソファ」「くつろげる」→ chair_type: ["ソファ"]
  - 「座り心地のいい椅子」「やわらかい椅子」→ chair_type: ["クッション椅子", "ソファ"]
  - 「背もたれがない椅子」「スツール」→ chair_type: ["スツール"]
  - 「背もたれのある椅子」→ chair_type: ["木製椅子", "通常椅子", "クッション椅子", "キャスター付き椅子", "ソファ"]
  - 「普通の椅子」→ chair_type: ["通常椅子"]
  - 「座れる」→ chair_type: ["木製椅子", "通常椅子", "クッション椅子", "キャスター付き椅子", "机一体型", "ソファ", "スツール"]
  - 「立ったまま」「スタンディング」→ standing: "可"
  - 「電源」「コンセント」「充電」→ outlets_required: true
  - 「〇人で」→ min_seats: 〇
  - 「手元が明るい」「作業灯」「デスクライト」→ task_light: "あり"
  - 「明日の3限」→ date: 今日の翌日, period: 3
  - 「10/2の4限」→ date: "2026-10-02"（年は今日の日付から、今日以降で一番近い日付）, period: 4
  - 「金曜3限」「金曜の3時間目」→ weekday: "金", period: 3（date は null）
  - 「3限に」（日付・曜日なし）→ period: 3 のみ
  - 「今」「今から」「これから使える」→ now: true（date・weekday・period は null）
  - 「教室」「空き教室」→ building: "講義棟"
- date・weekday・period・now は、質問文に時間の指定があるときだけ入れる。
- ひらがな・カタカナ・誤字・略語・変換ミスは、意味を汲み取って上の項目に対応づける（普通の言葉だけ。
  番号を含む固有名詞（「◯号館」「K◯◯◯」）は汲み取りの対象にしない）。例:
  - 「でんげん」「コンセンと」「こんせんと」「コンセ」「じゅうでん」→ outlets_required: true
  - 「しずか」「静かな」「しづか」→ quietness_max: "小声可"
  - 「ぐるーぷで」「グルプで」「はなしながら」→ quietness_min: "会話可"
  - 「つうわ」「でんわ」→ quietness_min: "通話可"
  - 「そふぁ」→ chair_type: ["ソファ"]
- 番号を含む固有名詞（「◯号館」「K◯◯◯」）は、番号を変えない。誤字に見えても直さず、番号の近い
  建物・教室にも置き換えず、質問文に書かれた番号のまま入れる。
  - 建物名は上の建物一覧にある表記に揃える（例:「図書館で」「としょかん」「図書」「とし館」→「図書館」、
    「こうぎとう」「講議棟」→「講義棟」）。「◯号館」で揃えるのは表記だけ（「21号」「21館」「２１号館」→「21号館」）。
  - 一覧のどの建物か確実に分からない、または一覧にない建物（例:「23号館」「1号館」「10号館」）は、
    一覧の建物に置き換えず、質問文の表記のまま building に入れる
    （例:「23号館はある？」→ building: "23号館"。一覧に「21号館」があっても「21号館」にはしない）。
  - 教室番号は、質問文の表記のまま room に入れる（例:「K53」→ room: "K53"。「K503」にはしない）。
- お知らせの確認（intent: "notice"）・口コミの確認（intent: "review"）・挨拶・雑談（intent: "chat"）は対応する（supported: true）。
- 次の質問はこのシステムでは答えられないので supported を false にし、unsupported_reason に対応していない内容を短い名詞句で書く（例:「混雑・空席の情報」「現在地からの距離」。「〜には対応していません」などは付けない）:
  - 混雑状況・席が空いているか・空席数（ただし「空いている教室」「明日の3限に使える場所」のように、授業・予約で使われていない教室を探す質問は対応する。date / weekday / period / now に入れる）
  - 現在地からの距離・近さ・行き方
  - 座席予約
  - 開館時間・営業時間
  - 作業スポット探しと無関係な質問（挨拶・お礼・雑談は除く）
  対応外の質問でも、質問文に書かれた建物（building）・場所（notice_place）は入れる（関係するお知らせを探すため）。
  それ以外は supported を true、unsupported_reason を null にする。
